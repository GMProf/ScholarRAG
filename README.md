# ScholarRAG

ScholarRAG é uma aplicação em desenvolvimento para consulta inteligente de artigos acadêmicos utilizando Retrieval-Augmented Generation (RAG).

O projeto está sendo construído de forma incremental, partindo dos fundamentos de APIs e processamento de documentos até recuperação semântica, bancos vetoriais e integração com modelos de linguagem.

## Status

Em desenvolvimento.

### Implementado

- API REST com FastAPI
- Endpoint de health check
- Endpoint para recebimento de perguntas
- Validação de dados com Pydantic
- Documentação automática com OpenAPI/Swagger

## Tecnologias atuais

- Python
- FastAPI
- Pydantic
- Uvicorn
